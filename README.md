# NormOS Lab

**Лабораторный прототип операционной системы нормативной реальности**

Проект по созданию первой инженерной реализации теории **нормативно-формализованной лингвистики**.

---

## 🎯 Цель проекта

Создать систему, способную **одинаково понимать** нормативный смысл (законы, регламенты, процедуры) как человек, так и машина, с гарантированным **Normative Alignment**.

---

## 📊 Текущий статус MVP (v0.1) — 13 июля 2026

**Достигнуто:**
- ✅ Полностью рабочий **Event System** + Event Store
- ✅ **Inference Engine** с подробной трассировкой
- ✅ Golden Tests с **Alignment Score = 100%** на ключевых сценариях
- ✅ NormFactory + парсинг нормативных глаголов
- ✅ NormGraph (визуализация переходов)
- ✅ Базовый Dashboard в Jupyter Lab
- ✅ Полный комплект архитектурных спецификаций (NKS-000 — NKS-009)

**Ключевой результат:**  
Система успешно выполняет полный цикл нормативного вывода и сохраняет историю событий.
