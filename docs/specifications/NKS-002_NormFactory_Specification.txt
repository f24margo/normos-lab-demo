## 1. Преамбула

В соответствии со **Статьями 3, 4 и 7** Конституции (NKS-000) настоящий документ определяет требования к **NormFactory** — подсистеме, отвечающей за преобразование естественного нормативного языка в формальные сущности NormOS.

NormFactory является **входными воротами** нормативной реальности в систему.

---

## 2. Назначение

NormFactory выполняет преобразование:
- Нормативных текстов → `NormGene`
- Описаний фактов → `NormFact`
- Запросов пользователей → `NormQuery`
- Контекста → `NormContext`

и публикует соответствующие события через **Event System** (NKS-001).

**NormFactory** — это конвейер формализации нормативного языка.

---

## 3. Архитектурные императивы (NKS-000)

- **Specification-First** — реализация строго следует настоящему документу.
- **Event-Driven First** — NormFactory **не** вызывает другие модули напрямую, а только публикует события.
- **Reproducibility** — процесс формализации должен быть детерминированным и воспроизводимым.
- **Single Source of Truth** — каждая сущность (`NormGene`, `NormFact` и т.д.) создаётся только через NormFactory.

---

## 4. Основные функции

### 4.1. Core Pipeline (MUST)

1. **Input Processing** — приём текста, документа или структурированных данных.
2. **Normalization** — очистка, сегментация, нормализация языка.
3. **Morphological Analysis** — выделение нормативных примитивов (Agent, Action, Object, State₁, State₂ и т.д.).
4. **NormVerb Parsing** — распознавание нормативных глаголов и привязка к реестру (см. NKS-001).
5. **Syntactic & Semantic Analysis** — построение нормативного перехода (`NormTransition`).
6. **Validation** — проверка полноты и корректности модели.
7. **Output** — создание формальной сущности + публикация события.

### 4.2. Обязательные события (NKS-001)

- `NormGeneCreated`
- `NormGeneUpdated`
- `NormFactCreated`
- `NormFactUpdated`
- `ParsingErrorOccurred`

## 6. Требования к реализации (MVP)

**MUST:**
1. Поддержка русского языка (украинского — в следующих версиях).
2. Гибридный подход: rules-based + LLM fallback.
3. Полная трассируемость каждого шага (trace в событиях).
4. Детерминированность при одинаковом входе (reproducibility).
5. Интеграция с **NormVerb Registry** (из NKS-001).
6. Публикация событий только через Event Bus.

**SHOULD:**
- Поддержка полуавтоматической разметки (человек + ИИ).
- Метрики качества формализации (confidence score).

## 7. Интерфейсы

```python
class NormFactory(ABC):
    async def process_text(self, text: str, source: str) -> ProcessingResult: ...
    async def process_fact(self, fact_description: str, context: dict) -> NormFact: ...
```

Результаты обработки **MUST** сопровождаться событиями.
