## 1. Преамбула

Настоящий документ определяет систему метрик и измерения качества NormOS, в первую очередь — **Normative Alignment** — главную метрику теории.

Без измерения качества нет науки.

---

## 2. Назначение

Metrics Layer обеспечивает:
- Количественную оценку качества нормативного вывода.
- Измерение степени согласования между человеком и машиной (**Normative Alignment**).
- Мониторинг производительности и надёжности системы.
- Объективные критерии приёмки модулей.

---

## 3. Главная метрика — Normative Alignment (NA)

**Normative Alignment** — степень совпадения нормативного вывода системы с выводом квалифицированного эксперта-человека.

### Формула (MVP)
```python
NA = (S_human ∩ S_system) / (S_human ∪ S_system)
```

где `S` — множество элементов решения (вердикт, обоснование, последствия, переходы).

**Шкала оценки:**
- < 0.6 — неприемлемо
- 0.6 – 0.75 — требует доработки
- 0.75 – 0.85 — приемлемо для MVP
- ≥ 0.85 — хорошо
- ≥ 0.95 — отлично (цель)

---

## 4. Дополнительные метрики

| Метрика                | Описание                                   | Цель MVP |
|------------------------|--------------------------------------------|----------|
| Soundness              | Корректность вывода                        | ≥ 0.9    |
| Completeness           | Полнота учёта норм                         | ≥ 0.85   |
| Traceability Score     | Полнота обоснования                        | 1.0      |
| Consistency            | Отсутствие внутренних противоречий         | 1.0      |
| Robustness             | Устойчивость к неполным данным             | ≥ 0.7    |
| Execution Time         | Время вывода                               | < 2 сек  |
