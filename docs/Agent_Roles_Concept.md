# Agent Roles Concept
**Концепція агентів з ролями в NormOS**

**Версія:** 0.1  
**Дата:** 26 липня 2026  
**Статус:** Концепт (не реалізовано)

---

## 1. Ідея

За аналогією з AI Agent Builder (Condor та подібні системи)  
NormOS вводить **агентів з ролями** як шар над Inference Engine.

Агент — це не просто чат-бот.  
Це **нормативний актор**, який:
- діє в межах своєї ролі (повноважень)
- використовує Event System, Registry і Inference
- залишає повний аудит-слід

## 3. Приклади ролей (МСУ)

| Роль | Повноваження | Типові дії |
|------|--------------|------------|
| **Секретар ради** | POW обмежені | перевірка протоколів, кворуму, підписів |
| **Юрист МСУ** | аналіз + рекомендації | перевірка відповідності закону, пропозиції правок |
| **Голова** | POW широкі | ініціація, підписання, скликання |
| **Депутат** | PERM / OBL | внесення проектів, голосування |
| **Аудитор** | контроль | перевірка виконання рішень |

---

## 4. Принципи

1. **Роль = набір дозволених переходів** (через POW / OBL / PROH)
2. **Агент не може вийти за межі ролі** (перевірка перед Inference)
3. **Усе через Event System** (жодна дія без події)
4. **Пояснюваність** — кожне рішення має Trace
5. **Модульність** — ролі можна підключати як пакети (NKS-008)

## 5. Зв’язок з архітектурою

| Компонент | Роль агента |
|-----------|-------------|
| NKS-001 Event System | фіксує дії агента |
| NKS-002 NormFactory | парсить запити агента |
| NKS-003 Inference Engine | обчислює рішення |
| NKS-006 Security | перевіряє права ролі |
| NKS-008 Package System | постачає доменні ролі |

## 6. Етапи впровадження

**Етап A (зараз)** — концепт + документ  
**Етап B** — одна роль «Юрист-аналітик» у Демо  
**Етап C** — кілька ролей + перевірка повноважень  
**Етап D** — Agent Builder (створення ролей через конфіг/UI)

---

## 7. Висновок

Агенти з ролями — природне розширення NormOS.  
Вони перетворюють систему з «калькулятора норм»  
на **операційну систему нормативної реальності**,  
де різні учасники діють у межах своїх повноважень.

**Не реалізуємо в поточному MVP.**  
Фіксуємо як архітектурний напрям для v0.2+.
