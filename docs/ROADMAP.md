# NormOS Lab — Roadmap

**Текущая версия:** MVP v0.1 (13 июля 2026)  
**Цель проекта:** Достичь устойчивого Normative Alignment ≥ 0.85 в домене местного самоуправления.

---

## ✅ Выполнено (MVP v0.1)

- Конституция проекта (NKS-000)
- Event System + Event Store
- NormFactory + парсинг нормативных глаголов
- Inference Engine с полным Trace
- NormGraph (базовая визуализация)
- Metrics & Golden Tests (Alignment Score)
- Базовый Dashboard в Jupyter
- Комплект спецификаций NKS-000 — NKS-009

**Ключевой результат:**  
Успешное прохождение Golden Tests с Alignment 100% на ключевых сценариях принятия решений.
